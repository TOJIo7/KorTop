# Roadmap: сайт вакансий для мигрантов

Дата: 26.10.2026

## О проекте

Сайт, где человек из Таджикистана ещё до поездки в Россию видит реальные вакансии, понимает условия и знает, какие документы нужны. Рабочее название: **KorTop** («кор» = работа по-таджикски, «топ» = найти; название можно поменять).

**Проблема.** Мигранты ищут работу через знакомых и случайные группы в Telegram. Условия непонятны, а мошенники берут деньги за «гарантированную работу».

**Решение.** Один понятный сайт на таджикском и русском: вакансии с фильтрами, чек-лист документов и предупреждения о мошенниках. Сайт работает с телефона, потому что аудитория в основном сидит с телефонов.

**Для кого:** мужчины и женщины 18–45 лет, которые едут на заработки впервые или меняют работу. Плохо знают русский, пользуются Android-телефоном.

### Функции MVP (обязательно для защиты)

- [ ] Главная: поиск, популярные города и профессии, последние вакансии
- [ ] Список вакансий с фильтрами: город, профессия, зарплата от, «есть жильё», «без русского», «официально»
- [ ] Сортировка: новые / зарплата по убыванию
- [ ] Страница вакансии: описание, условия, график, контакты, кнопка «В избранное»
- [ ] Избранное (сохраняется в localStorage)
- [ ] Раздел «Документы»: чек-лист патент / регистрация / медкомиссия со ссылками на официальные сайты
- [ ] Раздел «Осторожно, мошенники»: 6–8 признаков обмана
- [ ] Переключение языка: таджикский / русский
- [ ] Адаптив: телефон в первую очередь

### Только реальные данные

- [ ] Вакансии из официальной базы «Работа России» с ссылкой на оригинал
- [ ] Цена билета из Душанбе / Худжанда в выбранный город России
- [ ] Стоимость патента по региону + калькулятор «сколько останется»
- [ ] Курс рубля к сомони на сегодня
- [ ] Документы и сборы: только с официальных сайтов, с датой проверки

### Если останется время (бонус)

- Калькулятор «сколько останется»: зарплата минус патент, жильё, еда
- Карта с вакансиями
- Кнопка «Поделиться в Telegram / WhatsApp»

## Технологии

Стек: Next.js (App Router) на JavaScript. Next.js нужен, потому что данные берутся из настоящих API: сервер сам запрашивает их, кэширует и прячет секретные ключи от браузера.

| Что | Инструмент | Зачем |
| --- | --- | --- |
| Фреймворк | Next.js (App Router), последняя стабильная версия | Серверные компоненты, API-роуты, кэш данных |
| Стили | Tailwind CSS (выбрать при создании проекта) | Быстрая вёрстка и адаптив |
| Языки | next-intl | Адреса `/tg/...` и `/ru/...`, переводы интерфейса |
| Иконки | lucide-react | Бесплатные иконки |
| Даты | встроенный `Intl.DateTimeFormat` | «20 октября» на нужном языке, без лишних библиотек |
| Избранное | localStorage (клиентский хук) | Без регистрации и базы данных |
| Секреты | `.env.local` | Токен Travelpayouts не попадает в браузер |
| Код | Antigravity + Claude | Генерация и правка кода по этапам |
| Версии | Git + GitHub | История, ссылка для комиссии |
| Хостинг | Vercel | Бесплатно, Next.js работает «из коробки» |

Установить заранее: **Node.js (LTS)**, **Git**, аккаунты **GitHub**, **Vercel** и **Travelpayouts** (для цен на билеты).

Главное правило Next.js в этом проекте: страницы — серверные компоненты, они сами берут данные через `lib/`. Клиентские компоненты (`"use client"`) только там, где нужна интерактивность: фильтры, избранное, калькулятор, переключатель языка.

Правила раскладки:

- Компонент никогда не делает `fetch` к чужому сайту напрямую: только через функции из `lib/`.
- `lib/` возвращает данные уже в нашем формате (через `normalizeJob`), чтобы страницам было всё равно, откуда пришла вакансия.
- В `data/` у каждой записи есть `source` (ссылка) и `checkedAt` (дата проверки).
- Один компонент = один файл, имя с большой буквы.

## Источники данных

Всё, что видит пользователь, берётся из реальных источников. Справочники, у которых нет API (патент, документы), ты заполняешь сам с официальных сайтов и подписываешь источник и дату.

| Данные | Источник | Как получать | Важно |
| --- | --- | --- | --- |
| Вакансии | [API «Работа России»](https://trudvsem.ru/opendata/api) (Роструд) | `GET https://opendata.trudvsem.ru/api/v1/vacancies` и `/vacancies/region/{код}`; параметры `text`, `offset`, `limit`, `accommodation` (жильё), `modifiedFrom` | Ключ не нужен. API бывает медленным: таймаут и кэш на 1 час |
| Билеты | [Aviasales Data API](https://support.travelpayouts.com/hc/en-us/articles/203956163) через Travelpayouts | `GET https://api.travelpayouts.com/aviasales/v3/prices_for_dates?origin=DYU&destination=MOW&...&token=...` | Нужен бесплатный токен. Цены из кэша поисков, поэтому пишем «от … ₽» и ведём на Aviasales |
| Патент | Региональные законы + ФНС | Руками в `patents.json` | Меняется каждый январь |
| Курс ₽ → сомони | ЦБ РФ (`https://www.cbr.ru/scripts/XML_daily.asp`) или Нацбанк Таджикистана | Раз в день, кэш 24 часа | Проверь, что в ответе есть TJS |
| Документы | МВД России, Госуслуги, ММЦ Москвы, Миграционная служба Таджикистана | Руками в `documents.json` | Только официальные сайты, у каждого шага ссылка |

**hh.ru не используем:** [с апреля 2026 публичный поиск вакансий в его API закрыт](https://itlavka.com/hh-ru-zakryl-publichnyj-api-poiska-vakansij-posledstviya-dlya-razrabotchikov/) для неавторизованных запросов.

**Проверено на 26.10.2026 для патента:** стоимость = 1 200 ₽ × дефлятор × региональный коэффициент. На 2026 год дефлятор 2,842, в Москве патент стоит [10 000 ₽ в месяц](https://blog.mmc.help/soiskateli/avansovyy-platezh-za-patent-inostrannogo-grazhdanina-v-2026-godu-chto-eto-takoe-kto-i-kogda-platit-formula-i-primery-rascheta/). Для остальных регионов найди закон своего региона и запиши цифру с ссылкой.

### Наш формат вакансии (после `normalizeJob`)

```json
{
  "id": "trudvsem-<companyCode>-<vacancyId>",
  "source": "trudvsem",
  "title": "Подсобный рабочий",
  "employer": "ООО «...»",
  "region": "Москва",
  "city": "moscow",
  "salaryFrom": 70000,
  "salaryTo": 90000,
  "housing": true,
  "schedule": "Полный рабочий день",
  "requirements": "...",
  "url": "https://trudvsem.ru/vacancy/card/...",
  "postedAt": "2026-10-20"
}
```

Честность с данными:

- Тексты вакансий приходят только на русском. Интерфейс переводим на таджикский, а описание показываем как есть, с пометкой «текст работодателя».
- На каждой вакансии кнопка «Открыть на trudvsem.ru» и строка «KorTop не работодатель и не берёт денег за трудоустройство».
- Если API не ответил, показываем последние сохранённые данные с датой, а не выдумываем.
- Цены на билеты подписываем: «примерная цена по данным Aviasales, точная — при покупке».

## Этапы и задачи

Делай строго по порядку: каждый этап опирается на предыдущий. Этап закончен, когда выполнен пункт «Готово, если…». В конце каждого этапа делай коммит.

### Этап 0. Подготовка

- [ ] Установить Node.js (LTS) и Git, проверить: `node -v`, `git --version`
- [ ] Создать проект: `npx create-next-app@latest kortop` → JavaScript, ESLint: да, Tailwind: да, папка `src/`: нет, App Router: да, алиас импорта `@/*`
- [ ] Запустить: `cd kortop`, `npm run dev`, открыть `http://localhost:3000`
- [ ] Установить библиотеки: `npm install next-intl lucide-react`
- [ ] Удалить демо-код со стартовой страницы и лишние стили из `globals.css`
- [ ] Создать все папки из раздела «Структура папок»
- [ ] Создать `.env.example` и `.env.local`, проверить, что `.env.local` есть в `.gitignore`
- [ ] Положить в корень `ROADMAP.md` и `PRD.md`
- [ ] Создать репозиторий на GitHub, первый коммит, `git push`

**Готово, если:** `npm run dev` работает без ошибок, код на GitHub, секретов в репозитории нет.

### Этап 1. Проверка источников данных

Сначала убедись, что данные реально приходят, и только потом верстай.

- [ ] Открыть в браузере `https://opendata.trudvsem.ru/api/v1/vacancies?text=разнорабочий&limit=5` и посмотреть настоящую структуру ответа
- [ ] Сохранить пример ответа в `docs/samples/trudvsem.json`: по нему пишется `normalizeJob`
- [ ] Найти в [документации API](https://trudvsem.ru/opendata/api) коды регионов и параметр жилья (`accommodation`)
- [ ] Зарегистрироваться в Travelpayouts, подключить программу Aviasales, взять API-токен в профиле, положить в `.env.local` как `TRAVELPAYOUTS_TOKEN`
- [ ] Проверить запрос цен Душанбе (DYU) → Москва (MOW) и Худжанд (LBD) → Москва
- [ ] Открыть курс ЦБ РФ и проверить, есть ли там сомони (TJS)
- [ ] Если какой-то API не отвечает из Таджикистана, проверить его после деплоя с сервера Vercel; если не работает и там, записать это и делать запасной вариант (сохранённые данные)

**Готово, если:** по каждому источнику есть сохранённый пример ответа.

### Этап 2. Справочники

- [ ] `data/regions.json`: для каждого региона: `id`, название ru/tg, код региона trudvsem, код аэропорта (если есть: MOW, LED, SVX, KZN, OVB, KRR…)
- [ ] `data/patents.json`: стоимость патента в месяц по регионам, `year`, `source` (ссылка на закон или официальный сайт), `checkedAt`
- [ ] `data/documents.json`: шаги после въезда (миграционная карта, постановка на учёт, медосвидетельствование и дактилоскопия, получение патента, ежемесячная оплата), у каждого шага: описание ru/tg, срок, стоимость, `source`, `checkedAt`
- [ ] `data/scams.json`: 6–8 признаков обмана и «что делать, если обманули»
- [ ] Все цифры (сроки, сборы, цены) — только с официальных сайтов. Если не нашёл официального источника, не пиши цифру

**Готово, если:** у каждой записи в `data/` заполнены `source` и `checkedAt`.

### Этап 3. Каркас, дизайн, языки

- [ ] Настроить next-intl: `i18n/routing.js` (языки `tg`, `ru`, по умолчанию `tg`), `i18n/request.js`, `middleware.js`, папка `app/[locale]/`
- [ ] `messages/tg.json` и `messages/ru.json`: с самого начала писать все тексты интерфейса через `t('ключ')`
- [ ] Выбрать 2 цвета и шрифт (через `next/font`, например Inter или Manrope с кириллицей)
- [ ] `components/ui`: Button, Badge, Input, Select, Skeleton
- [ ] Header: логотип, меню (Вакансии, Билеты, Патент, Документы, Мошенники, Избранное), переключатель ТҶ / РУ
- [ ] Мобильное меню (бургер)
- [ ] Footer: «Источники данных», ссылка на GitHub, «KorTop не берёт денег за трудоустройство»
- [ ] Страницы-заглушки для всех адресов и `not-found.jsx`

**Готово, если:** все страницы открываются на обоих языках, переключатель меняет язык без перезагрузки на другую страницу.

### Этап 4. Вакансии с реальными данными

- [ ] `lib/trudvsem.js`: функция `searchJobs({ text, region, housing, offset, limit })`, таймаут 10 секунд, кэш `fetch(url, { next: { revalidate: 3600 } })`
- [ ] `lib/normalizeJob.js`: превращает ответ API в наш формат (раздел «Источники данных»)
- [ ] `lib/format.js`: зарплата «от 70 000 ₽», дата на нужном языке
- [ ] `app/[locale]/jobs/page.jsx`: серверный компонент, читает фильтры из `searchParams`, вызывает `searchJobs`
- [ ] JobCard: название, работодатель, регион, зарплата, метка «Жильё», дата
- [ ] JobFilters (клиентский): поиск, регион, «с жильём»; меняет адрес (`?text=...&city=...&housing=1`), а страница перезапрашивает данные
- [ ] Pagination: «Ещё вакансии» или номера страниц через `offset`
- [ ] Состояния: загрузка (`loading.jsx` со скелетонами), ошибка API (`error.jsx` с кнопкой «Повторить»), пусто (EmptyState)
- [ ] Готовые быстрые фильтры для мигрантов: «Стройка», «Склад», «Доставка», «Общепит», «Уборка»

**Готово, если:** фильтр «Москва + с жильём» показывает настоящие вакансии, а ссылкой с фильтрами можно поделиться.

### Этап 5. Страница вакансии и избранное

- [ ] `jobs/[id]/page.jsx`: загрузить одну вакансию (эндпоинт `/vacancies/vacancy/{companyCode}/{vacancyId}`)
- [ ] Показать всё: зарплату, условия, требования, график, работодателя, регион
- [ ] Кнопка «Открыть на trudvsem.ru» (оригинал) и пометка «текст работодателя»
- [ ] Блок «Сколько останется» с ценой патента для этого региона (из `patents.json`)
- [ ] Если вакансия не найдена или закрыта: понятное сообщение и ссылка назад
- [ ] `hooks/useFavorites.js`: хранит в localStorage **копии** вакансий (не только id), чтобы избранное открывалось, даже если вакансию убрали
- [ ] Сердечко на карточке и на странице, страница `/favorites`, счётчик в Header
- [ ] `generateMetadata`: заголовок вкладки = название вакансии (для красивой ссылки в Telegram)

**Готово, если:** избранное не пропадает после перезагрузки, у каждой вакансии есть ссылка на оригинал.

### Этап 6. Билеты и курс валют

- [ ] `lib/travelpayouts.js`: функция `getCheapestPrices({ origin, destination, month })`, токен только из `process.env`, кэш 6 часов
- [ ] `app/api/tickets/route.js`: прокси для клиентского поиска (токен не уходит в браузер)
- [ ] Страница `/tickets`: откуда (Душанбе / Худжанд), куда (города из `regions.json`), месяц → список самых дешёвых дат и цен «от …»
- [ ] Кнопка «Смотреть на Aviasales» с твоей партнёрской ссылкой (это и есть будущий заработок)
- [ ] Подпись: «Примерная цена по данным Aviasales на дату …»
- [ ] `lib/rates.js`: курс ₽ → сомони, кэш 24 часа; рядом с зарплатой показывать «≈ N сомони»
- [ ] Если API не ответил: показать последние данные с датой или «Цены временно недоступны»

**Готово, если:** для Душанбе → Москва на выбранный месяц видны реальные цены и дата их актуальности.

### Этап 7. Патент, документы, мошенники

- [ ] `/patent`: таблица стоимости патента по регионам с источниками и датой проверки
- [ ] PatentCalculator (клиентский): зарплата − патент − жильё − еда − транспорт = сколько останется в рублях и сомони
- [ ] `/documents`: пошаговый чек-лист из `documents.json`, галочки сохраняются в localStorage

## Как работать с Antigravity и Claude

ИИ пишет код быстро, но ты должен понимать каждый файл: на защите спросят. Давай задачи маленькими кусками, по одному пункту этапа за раз.

### Правила для агента

Положи этот текст в файл правил проекта (например `AGENTS.md` в корне или в правила рабочей области Antigravity) и вставляй его в начало нового чата с Claude.

```markdown
# Правила проекта KorTop

Проект: сайт вакансий для трудовых мигрантов из Таджикистана в Россию.
План и структура папок: ROADMAP.md. Требования: PRD.md. Не отходи от них без моего согласия.

Стек: Next.js (App Router), JavaScript (не TypeScript), Tailwind CSS, next-intl, lucide-react.

Правила:
- Делай только ту задачу, которую я дал. Не трогай другие файлы без причины.
- Перед изменениями коротко напиши план: какие файлы создашь или изменишь.
- Страницы — серверные компоненты. "use client" только для интерактивных частей.
- Внешние API вызываются только из lib/. Токены только из process.env.
- Никаких выдуманных данных: вакансии, цены, курсы только из API или из data/ с полем source.
- Все тексты интерфейса через next-intl (messages/tg.json и messages/ru.json), без текста прямо в JSX.
- Mobile-first: сначала вёрстка для 360 px.
- Обрабатывай загрузку, ошибку и пустой результат.
- Простой и понятный код, короткие комментарии на русском там, где логика неочевидна.
- После изменений скажи, как проверить, что всё работает.
```

### Как ставить задачу

1. Скопируй один пункт из этапа.
2. Добавь контекст: какие файлы уже есть, пример ответа API (если задача про данные).
3. Попроси сначала план, потом код.
4. Запусти и проверь сам. Не работает — отправь агенту текст ошибки целиком.
5. Попроси объяснить код простыми словами. Не понимаешь — не коммить.
6. Коммит.

### Готовые промпты

**Старт этапа:**

```
Прочитай ROADMAP.md, PRD.md и AGENTS.md. Сейчас делаем Этап <N>, пункт: «<текст пункта>».
Сначала напиши план (какие файлы и зачем), подожди моего «ок», потом пиши код.
```

**Нормализация API:**

```
Вот реальный пример ответа API «Работа России» из docs/samples/trudvsem.json: <вставить>.
Напиши lib/normalizeJob.js, который превращает одну вакансию в наш формат из ROADMAP.md (раздел «Наш формат вакансии»).
Если поля нет — null, ничего не выдумывай.
```

**Ошибка:**

```
После <что сделал> появилась ошибка: <текст ошибки целиком>.
Файл: <путь>. Объясни причину простыми словами и исправь минимальным изменением.
```

**Проверка перед коммитом:**

```
Проверь мои изменения в <файлы>: есть ли ошибки, лишний код, тексты без перевода,
токены в клиентском коде, проблемы на ширине 360 px. Только список замечаний, без переписывания.
```

**Подготовка к защите:**

```
Объясни, как работает <файл/функция>, так, чтобы я мог рассказать это комиссии за 1 минуту.
Потом задай мне 5 вопросов, которые может задать комиссия.
```

## Правила кода и Git

### Код

- Имена: компоненты `PascalCase` (`JobCard.jsx`), функции и переменные `camelCase` (`searchJobs`), файлы в `lib/` и `hooks/` тоже `camelCase`
- Один компонент = один файл, до ~150 строк. Длиннее — разбей
- Импорты через алиас: `@/components/jobs/JobCard`
- Ключи переводов по разделам: `jobs.filters.housing`, `header.menu.tickets`
- Никаких `console.log` в коммитах
- Секреты только в `.env.local` и в настройках Vercel

### Git

- Ветка `main` всегда рабочая. Новая задача → своя ветка: `feat/job-filters`, `fix/ticket-price`
- Коммит после каждого законченного пункта, сообщение по-английски в формате:
  - `feat: add job filters`
  - `fix: handle empty trudvsem response`
  - `style: mobile header`
  - `docs: update README`
- Перед коммитом: `npm run build` без ошибок
- Слил ветку в `main` → Vercel сам обновит сайт

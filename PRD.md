# PRD: KorTop — работа в России для мигрантов

Дата: 26.10.2026

KorTop — бесплатный мобильный сайт, где трудовой мигрант из Таджикистана находит реальную вакансию в любом регионе России, узнаёт цену билета и патента и понимает, какие документы оформить. Разработчик один, регистрации нет, все данные из официальных источников.

## Обзор

**Проблема.** Мигранты ищут работу через знакомых и группы в Telegram. Условия часто непонятны, цены на билеты и патент приходится искать по разным сайтам, а мошенники берут деньги за «гарантированную работу».

**Решение.** Один сайт на таджикском и русском, который собирает в одном месте:

- реальные вакансии из официальной базы «Работа России» по всей стране;
- цены на билеты из Душанбе и Худжанда;
- стоимость патента по регионам и калькулятор «сколько останется»;
- курс рубля к сомони;
- чек-лист документов и предупреждения о мошенниках.

| Цель | Как измерить | Целевое значение |
| --- | --- | --- |

**Не цели:** заработок в первой версии, приём откликов на вакансии, собственная база работодателей.

## Пользователи и сценарии

| Кто | Что о нём знаем | Что ему нужно |
| --- | --- | --- |
| **Фаррух, 23 года**, едет впервые | Android-телефон, мобильный интернет, русский знает слабо | Понять, где есть работа с жильём, сколько стоит дорога и какие документы оформить |
| **Рустам, 35 лет**, уже работал в России | Знает русский, хочет сменить работу или город | Сравнить зарплаты по регионам и понять, сколько останется после патента |
| **Родственник мигранта** в Таджикистане | Помогает найти работу и купить билет | Найти вакансию и показать её родственнику, отправить ссылку |

### Ключевые сценарии

1. **Найти работу с жильём.** Главная → выбрать регион и профессию → включить «с жильём» → открыть вакансию → перейти к оригиналу на trudvsem.ru или позвонить.
2. **Посчитать, выгодно ли ехать.** Вакансия → блок «Сколько останется»: зарплата минус патент региона минус жильё и еда, в рублях и сомони.
3. **Узнать цену дороги.** Билеты → откуда (Душанбе / Худжанд) → куда → месяц → самые дешёвые даты → «Смотреть на Aviasales».
4. **Подготовить документы.** Документы → пошаговый чек-лист с отметками → ссылки на официальные сайты.
5. **Проверить подозрительное предложение.** Мошенники → сравнить с признаками обмана → понять, куда обращаться.
6. **Поделиться.** Любая вакансия или поиск с фильтрами открывается по ссылке, которую можно отправить в Telegram или WhatsApp.

## Объём

Первая версия охватывает всю Россию и шесть разделов. Регистрации и своей базы данных нет: всё, что пользователь сохраняет, хранится в его браузере.

| Раздел | В MVP | Не в MVP |
| --- | --- | --- |
| Вакансии | Поиск по всем регионам, фильтры, карточка, ссылка на оригинал, избранное | Отклик через сайт, размещение вакансий работодателями |
| Билеты | Самые дешёвые даты из Душанбе / Худжанда во все города с аэропортом | Покупка на сайте, поезда и автобусы |
| Патент | Таблица по регионам, калькулятор «сколько останется» | Оплата патента через сайт |
| Курс | ₽ → сомони на сегодня, пересчёт зарплаты | История курса, другие валюты |
| Документы | Пошаговый чек-лист с отметками и ссылками | Запись в миграционный центр, заполнение заявлений |
| Мошенники | Признаки обмана, куда обращаться | Жалобы пользователей на работодателей |
| Напоминания | Telegram-бот напоминает о сроках, которые человек сам ввёл на сайте, и присылает новые вакансии по подписке | Аккаунты, push-уведомления, SMS |
| Общее | Таджикский и русский, телефон в первую очередь | Аккаунты, оплата |

## Данные и источники

Правило: на сайте нет ни одной выдуманной цифры. Каждое значение либо приходит из API, либо внесено вручную с официального сайта со ссылкой и датой проверки.

| Данные | Источник | Тип | Обновление |
| --- | --- | --- | --- |
| Вакансии | [API «Работа России»](https://trudvsem.ru/opendata/api) (Роструд), без ключа | API | Кэш 1 час |
| Билеты | [Aviasales Data API](https://support.travelpayouts.com/hc/en-us/articles/203956163) через Travelpayouts, бесплатный токен | API | Кэш 6 часов |
| Курс ₽ → сомони | ЦБ РФ или Нацбанк Таджикистана | API | Кэш 24 часа |
| Патент по регионам | Законы субъектов РФ, сайты ФНС и МВД | Вручную | Каждый январь |
| Документы и сборы | МВД России, Госуслуги, миграционные центры, Миграционная служба Таджикистана | Вручную | Раз в месяц и при новостях об изменениях |
| Признаки мошенничества | Официальные памятки МВД и миграционных служб | Вручную | По необходимости |

Проверенные факты на 26.10.2026:

- [Публичный поиск вакансий в API hh.ru закрыт с апреля 2026](https://itlavka.com/hh-ru-zakryl-publichnyj-api-poiska-vakansij-posledstviya-dlya-razrabotchikov/), поэтому hh.ru не используется.
- Патент = 1 200 ₽ × дефлятор × региональный коэффициент; [в 2026 году дефлятор 2,842, в Москве патент 10 000 ₽ в месяц](https://blog.mmc.help/soiskateli/avansovyy-platezh-za-patent-inostrannogo-grazhdanina-v-2026-godu-chto-eto-takoe-kto-i-kogda-platit-formula-i-primery-rascheta/).
- Цены Aviasales Data API берутся из кэша недавних поисков, поэтому показываются как «от … ₽», а не как точная цена.

Правила отображения:

- Рядом с каждой цифрой из ручных справочников: ссылка на источник и дата проверки.
- У каждой вакансии: ссылка на оригинал.
- Нет данных — пишем «нет данных», а не подставляем примерное значение.

## Риски, допущения и открытые вопросы

### Риски

| Риск | Что делаем |
| --- | --- |
| API «Работа России» медленный или недоступен из Таджикистана / с серверов Vercel | Проверить на первом этапе; таймаут 10 с, кэш, показ последних данных с датой |
| Вакансий для мигрантов в официальной базе мало, многие требуют гражданство РФ | Быстрые категории под рабочие профессии; честно показывать, что нашлось |
| Патент для всех 89 регионов долго проверять вручную | Сначала регионы с наибольшим спросом, остальные «нет данных» (P-2) |
| Ошибки в информации о документах навредят людям | Только официальные источники, дата проверки, плашка «правила меняются» |
| Travelpayouts не одобрит или нет цен по направлению | Показывать ссылку на Aviasales без цены (T-4) |
| Один разработчик, много разделов | Сначала все «Обязательно», «Желательно» только после |

### Допущения

- Пользователи заходят с телефона и готовы открыть ссылку из Telegram или WhatsApp.
- Для защиты достаточно рабочего сайта без аккаунтов и своей базы данных.
- Тексты вакансий можно показывать на русском, если интерфейс на таджикском.
